# Interactive FAQ

Find answers to common questions about SecureHealth with our interactive FAQ. Filter by role, search for specific topics, and explore questions in an organized, easy-to-navigate format.

<FAQAccordion faqData={faqData} />

## Key Features

- **Role-based filtering**: Quickly find questions relevant to your role (Developer, Healthcare Provider, IT Administrator, Decision Maker)
- **Search functionality**: Search across all questions and answers
- **Accordion interface**: Clean, organized display with expandable answers
- **Mobile responsive**: Works perfectly on all devices
- **Accessibility**: Full keyboard navigation and screen reader support

## Quick Navigation

- **Developers**: Technical implementation, security, and development questions
- **Healthcare Providers**: System usage, data security, and workflow integration
- **IT Administrators**: Installation, security management, and compliance
- **Decision Makers**: Business value, implementation costs, and risk management
- **General**: Getting started and technical support
